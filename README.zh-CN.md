# OpenSweep

**免费开源的电脑清理工具：删之前用大白话告诉你要删什么、为什么能删。**

[English](README.md)

没有广告，没有“升级专业版”，不收集任何数据。只有你点“检查更新”（或在设置里打开自动检查）时才会联网。

## 能做什么

| | |
|---|---|
| **电脑体检** | 一键检查垃圾文件、开机启动、不用的软件、磁盘空间和内存，打分并逐条解释，点一下就能按建议处理；处理完告诉你变好了多少、还剩什么、为什么。 |
| **垃圾文件** | 临时文件、更新残留、浏览器和各种软件的缓存。每一项都说明是什么、能不能删，删除前能看到里面具体有哪些文件。 |
| **AI 模型和缓存** | Hugging Face、Ollama、LM Studio、魔搭、PyTorch、Whisper 的模型逐个列出，还有 Cursor/Claude/Trae 缓存和开发缓存（pip、npm、uv、Gradle 等）。删除 Ollama 模型不会破坏其他模型共用的数据。 |
| **磁盘分析** | 用方块图显示磁盘被什么占满，颜色表示“能不能删”，常见系统文件夹都有大白话说明（pagefile.sys、WinSxS、聊天记录……）。以管理员身份运行时直接读取 NTFS 文件表，机械硬盘也很快。 |
| **软件管理** | 已安装软件的最后使用时间估算、卸载和残留清理，还能找出**Windows 自己都不知道的程序**（解压即用的绿色软件、卸载后留下的文件夹）。 |
| **开机启动** | 注册表启动项、启动文件夹、计划任务和第三方服务，每一项都有建议（建议关闭 / 看个人需要 / 建议保留）和理由，修改随时可以改回来。 |
| **内存** | 哪些软件在占内存、哪些只在后台运行，以及为什么我们故意不做“一键释放内存”。 |

支持 10 种语言。

## 安全

- 删除前会经过一份写死的保护名单（Windows、Program Files、文档/桌面/图片等），任何规则都绕不过去。
- 不跟随快捷链接和目录联接，不可能删到选中范围以外的东西。
- 正在使用的文件会跳过，不会强删；“需查看”的项目默认放进回收站。
- 每次清理都记录在 `%APPDATA%\OpenSweep\logs`。
- 不会动文档、照片、视频、下载的文件、聊天记录、游戏存档、密码和浏览器登录状态。

## 下载

在 [Releases](https://github.com/opensweep/opensweep/releases) 下载安装包 `OpenSweep-x.y.z-setup.exe` 或免安装压缩包。支持 Windows 10/11 64 位。

以管理员身份运行，可以清理 Windows 自己的垃圾（更新缓存、系统临时文件），磁盘分析也会快很多。

## 参与贡献

最有用的贡献不需要写代码：**清理规则、开机启动建议、文件夹说明都是 JSON 文件**，详见 [CONTRIBUTING.md](CONTRIBUTING.md) 和 [docs/RULES.md](docs/RULES.md)。
发现 OpenSweep 说错了？点任意一项下面的“说得不对？”，会打开一个自动填好的反馈页面。
