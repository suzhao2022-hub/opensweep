# OpenSweep 测试版招募说明

> 这份说明可以直接转发给愿意帮忙测试的朋友。

感谢你帮忙测试 OpenSweep！这是一个免费开源的电脑清理工具，现在想在更多不同的电脑上检验它的判断准不准。

## 怎么测

1. 下载免安装版压缩包，解压后**右键 OpenSweep.exe → 以管理员身份运行**。
   - 如果出现“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”（测试版还没有签名）。
2. 点首页的“开始体检”，**先不要点任何清理按钮**，逐项看看：
   - 它说“可以放心清理”的东西，你觉得真的能删吗？
   - 它说“别动 / 需要你判断”的东西，判断对吗？
   - 有没有你电脑上明显很占空间、但它没发现的东西？
3. 再看看“磁盘分析”“软件管理”“开机启动”这几页，同样只看不删。
4. 觉得没问题了，再试一下清理，看看清理后软件、浏览器登录、聊天记录是否一切正常。

## 发现问题怎么反馈

- 每一项详情的最下面都有 **“说得不对？”**，点一下会在浏览器里打开一个自动填好的反馈页面（需要 GitHub 账号）。
  里面的用户名已经替换掉了，发送前你可以再检查、删改。
- 没有 GitHub 账号的话，把截图和你看到的问题直接发给我们也可以。

## 我们最想知道的

- 有没有把**你的文件**（照片、文档、聊天记录、游戏存档）当成可以删的东西？——这是最严重的问题。
- 哪些说明你看不懂？
- 清理以后有没有哪个软件出问题？
- 你用的是什么电脑（机械硬盘还是固态硬盘、Windows 10 还是 11）、装了哪些常用软件？

清理记录保存在 `%APPDATA%\OpenSweep\logs`，出问题时把这个文件夹里的文件一起发给我们会很有帮助。
